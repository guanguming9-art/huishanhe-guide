六讲定稿

完整讲义

绘山河创意工坊 · 六讲教程（定稿存档）

来源：游戏内《国家使命》《触发器》百科全量备份（用户提供）+ B 站 itsafool 三支视频 + 编辑实机。 用途：本工作区的知识底座；每次改剧本、写配置都以本文件为准。

第 1 讲 · 是什么 · 谁能写 · 全流程

定义

绘山河是《无悔华夏》内置的自创剧本工坊：用官方剧本当底模，重画疆域、重配势力、重写剧情，发布给别人玩。

两种身份

  • 游玩者：通关任一主时代剧本。
  • 绘师：通关四个主时代剧本且全部一星以上 + 同意《创作者协议》。战役、传记暂不作底图。

绘师等级

经验按他人游玩的平均胜率与时长结算，胜率过高或过低都不给经验。等级解锁发布数量与草稿位。

五步流程

选底图 → 地图编辑 → 国家编辑 → 城市编辑 → 剧情编辑；底部另有国家使命、触发器。

三层结构

层内容决定
数据层地图 + 国家 + 城市开局长什么样
叙事层剧情玩家看到什么
逻辑层国家使命 + 触发器世界怎么运转

顺序铁律

先定结局 → 倒推使命链 → 补触发器 → 写剧情 → 压数值。反做必返工。

第 2 讲 · ① 选底图 ② 地图编辑

选底图

底图只给地图骨架，不锁年代。例：做「五国伐齐」可借汉末三国大地图。绘本标签不绑底图时代。

地图编辑

子页内容
剧本详情名称、年份、可玩势力（多选）、BGM
介绍界面进入时的介绍语
封面与简介素材库背景 + 人物素材拼封面
绘本标签架空、小型地图等，决定曝光

坑：可玩势力必须在这一页勾，编辑过的国家≠可玩国家。

第 3 讲 · ③ 国家编辑 ④ 城市编辑

国家编辑

  1. 覆盖国家设置：整套国家数据（数值/特有兵种/美术）覆盖进来，跨时代混搭的正规途径。坑：跨时代特殊资源不带过来，须手动重配。
  2. 初始编辑国家 / 选择其他国家：划版图、增删国家。
  3. 国君信息：头像、旗帜、名字、国号、性格。
  4. 国家数值：初始军规、战斗力、钱粮、特资、首都、势力颜色。
  5. 战场：初始兵种、特色子弟兵、特色国家卡牌。
  6. 势力介绍：常规介绍 + 灭国专属描述（单独一栏，最易漏）。
  7. 势力标签：纯展示，无数值影响。

城市编辑

  1. 城市等级 + 所属国家：逐城改归属＝重画国界。
  2. 治所 / 要地互转：改战略价值。
  3. 隐藏城市：小地图高密度剧本的关键。
  4. 城市资源：军心、民心、腐化、人口、兵力、产出、城防。
  • 拖时间：边城城防满 + 人口低
  • 内政压力：腹地腐化高
  • 逼外交：敌首都塞满兵

与触发器联动的两条硬限制：

  • 检测城市参数在某范围内 只对治所生效，不含要地
  • 判断国家城市等级之和 排除隐藏城与要地

第 4 讲 · ⑤ 剧情编辑 ⑥ 国家使命

剧情编辑

  • 文本库：通用文本复用，避免手打重复
  • 撰写新情节：局内对话，逐幕配头像 + 台词
  • 关键节点：每势力 开场 / 胜利 / 失败
  • 详细剧情：三种触发——消灭某国 / 占领特定城池 / 随时间推移

铁律：剧情页挂不住复杂条件，判断交给使命或触发器。

国家使命（四段）

  1. 基础设定：绑定国家、参数、特性
  2. 可见条件：满足后才出现在任务列表
  3. 完成条件：玩家目标
  4. 达成效果：奖励与特殊效果

字段清单

字段规则
使命标题≤7 字
编辑器序号仅编辑器内排序
排序游戏内顺序，从小到大
可见国家多选；条件中“挂载国家”按国家分别计算
使命类型普通（不出结局）/ 终局（出结局）
可重复完成条件须含计数条件（如计时器），完成后清零重计
不可见隐藏开启后条件不满足会再藏回去
奖励说明≤20 字
奖励项目≤6 字 + 图标
是否显示效果默认不勾

达成效果参数池

  • 国家属性：战斗力、军团规模、威望、科技值、用间等级、全国军队、文化值、修行/乐感等级、朴素信仰、各级兵种等级、全国人口、野兽等级
  • 城市属性：民心、军心、腐败、城市耐久、城市人口、城市用间防御
  • 资源：士子、铁、歌板、马匹、丝绸、城市兵甲、良驹、商队、玄机、词源、酒、香料、熏衣…
  • 特殊取值：治所数量、盟国藩属国数、最高城市等级、损失兵甲、名臣姓名字数、女性名臣数、好感>90 国家数、武将数、人口倍数（100 万/500 万）、存活/已灭亡国家数、治所地块数和、累计战斗次数、主时代通关数、5 级及以上城市数、完成的时代政策数
关键联动：触发器 检测国家参数在某范围内 的参数 = 这张表。

第 5 讲 · ⑦ 触发器

三个模块

基础设定 / 达成条件（只能一个）/ 达成效果

基础设定五字段

挂载对象（国家/全局）、初始启用、循环触发、效果目标、编辑器序号

四条规则

  1. 挂载国家多选 = 多份独立副本；挂载国灭亡则该副本失效
  2. 挂载全局 = 不随灭国消失，但条件与效果都须指定具体国家/城市，效果目标只能一个
  3. 初始启用不勾 → 必须被效果添加并开启；被效果添加的一定初始关闭
  4. 循环三前提：条件含不取反的计数条件；达成后计数重计；新添加/曾关闭的初始非循环，需设为循环

条件库 21 条

逻辑组件（3）

条件说明
判断满足条件数（多条件复合）≥N 条满足；N=1 为“或”，N=全部为“与”
判断不满足条件数（多条件复合）≥N 条不满足
返回与否恒假；取反后恒真

基础（6）：检测目标国家存活 / 拥有指定的所有城市 / 检查目标国家是否为玩家 / 计时器（计数判断）/ 检测目标国家是否在列表中 / 玩家是否曾携带武器战斗

属性状态（6）：检测国家参数在某范围内（特性主来源）/ 已完成国家使命 / 检测目标城市是否在列表中 / 检测城市参数在某范围内（仅治所）/ 检测两国好感度 / 判断国家城市等级之和范围（排除隐藏与要地）

属性计数（6）：累计计算触发次数（持久、可循环）/ 触发时机匹配（瞬时、不保存、不可循环）/ 累计计算获取的特殊资源数 / 累计进攻大捷次数（限制战损｜限制打出卡牌｜限制时间）

三个机关

  1. 与/或/非：N=1 或、N=全 与；返回与否+取反 = 恒真（站位置）；单独返回与否 = 恒假（废掉触发器）
  2. 边沿 vs 电平：触发时机匹配 只那一瞬；累计计算触发次数 达成后一直真。选错会导致“事后补条件也发奖励”
  3. 六兄弟：添加、开启、关闭、移除、设为循环、取消循环。不能自调用（只响一次），循环靠 1↔2 互相拉起；频率过高会被静默掐断

三个坑

  • 多国挂载 + 全局效果 = ×N
  • 特资是唯一自由寄存器（读：检测国家参数→资源；写：效果→资源；数：累计计算获取的特殊资源数），易被其他系统污染
  • 循环被掐 / 挂载国被灭 → 静默停摆

第 6 讲 · 配合 · 实操 · 检查单

分工

使命给选择权（主线/分支/结局）；触发器暗中改世界（特性/难度/隐藏机制）；剧情只演。 触发器不做结局；条件不稀有就别用触发器插剧情。

四种范式

  1. 事件链：B 的可见条件写“已完成使命 A”
  2. IF/ELSE：成对触发器同时拉起，效果里移除对方（互斥锁）
  3. 状态机：六兄弟开关，每次拉起配 开启 + 设为循环
  4. 伪随机：计时器给特资加值 → 两个触发器互相调用做取模 → 读特资分派分支；加强：改步长、加长周期计数器（1s+4/5s+1/7s+2，周期 5 分 15 秒）、扩值域或加第二种特资

实操：雪夜入蔡州

T1 困兽：挂载 国家·淮西｜初始启用 ☑｜循环 ☑｜效果目标 挂载国家 条件 判断满足条件数 3：① 计时器 10 ② 检测国家参数 治所数量 0–2 ③ 检测城市参数 蔡州·民心 0–39 效果 国家战斗力 +X（军团规模单位是人）

T2 破城：挂载 全局｜初始启用 ☑｜循环 ☐｜效果目标 玩家国家 条件 判断满足条件数 2：① 触发时机匹配 进攻战斗胜利 ② 检测目标城市是否在列表中 蔡州 效果 触发剧情 + 添加触发器/开启触发器 T3

T3：初始启用 ☐；条件 返回与否+取反（恒真）；效果 关闭触发器 T2 → 添加并开启 T4、T5 T4：①淮西存活 ②治所 0–2；效果 移除 T5、拉起 T6 T5：恒真；效果 移除 T4、拉起 T7

检查单

  1. 循环条件里有不取反的计数条件吗
  2. 多国 × 全局效果 = ×N，是对的吗
  3. 一次性用边沿、长期用累计，对吗
  4. 城市条件只看治所、等级和排除隐藏与要地，对得上吗
  5. 新拉起的触发器补了 开启 与 设为循环 吗
  6. 字数：7 / 20 / 6
  7. 该外显的效果勾了吗

待验证清单

国家使命

字段全解

无悔华夏 · 绘山河 · 国家使命（用户整理稿）

来源：用户本人整理，2026-11-16 提供。未经我改写，仅做排版。

一、国家使命综述

（一）简述

  1. 国家使命是玩家操作剧本可见的“任务系统”。
  2. 分为普通使命和终局。
  3. 对应官方剧本中推动流程的“国家使命”任务栏，创作者可自行设计。
  4. 一条完整的国家使命通常由四部分构成：基础设定、可见条件、完成条件、达成效果。

（二）四部分

  1. 基础设定：设立绑定国家、基础参数和特性。
  2. 可见条件：满足后该使命可见；决定何时/因何事出现在玩家任务列表。
  3. 完成条件：满足后该使命可被完成；即玩家要达成的目标。
  4. 达成效果：完成使命后获得的效果。

（三）预览与绑定国家

  1. 编辑完成后可在编辑界面预览国家使命界面。
  2. 绑定国家不同，每个国家可用的使命也不同。

二、模块解说

（一）使命名称

  • 使命标题：可编辑，7 个字以内。

（二）编辑器序号

  • 用于确定使命在编辑器内的序号；不影响游戏内排序，仅供编辑器内便利使用。

（三）排序

  • 决定游戏内国家使命排序优先级，从小到大排。

（四）可见国家

  • 决定该使命能被哪些国家使用，可选多个。
  • 注意：在条件中选择挂载国家对象时，记录的是挂载的每个国家本身，分开计算条件。

（五）使命类型

  • 普通使命：不触发结局，用于事件或某种战役等。
  • 终局使命：触发结局，用于特定数值（如民心低于 10 触发叛乱失败终局）或统一结局等。

（六）可重复完成

  • 表明该使命能否被重复完成。
  • 条件中必须存在计数类型条件（如【计时器】），否则可能被无限完成。
  • 达成完成条件并完成后，计数类型条件会清零并重新计数。

（七）不可见隐藏

  • 不满足可见条件隐藏：决定使命是否可被二次隐藏。
  • 开启后：可见条件不满足时，使命会重新隐藏。
  • 示例：可见条件设为【秦】国家存在，则秦灭亡时该任务变为不可用状态。

（八）奖励说明

  • 与奖励项目一起绑定达成效果，是完成使命后的奖励描述。
  • 至多 20 个字，建议一句话说清。

（九）奖励项目

  • 奖励说明与奖励项目绑定达成效果。
  • 奖励描述绑定一个图标，并用至多 6 个字简要说明效果。

（十）奖励效果（达成效果/完成效果）

注：触发条件里「属性状态 → 检测国家参数在某范围内」的参数，同样选择这里的这些效果项。

1. 国家属性 国家战斗力、军团规模、威望、科技值、用间等级、全国军队、文化值、修行等级、乐感等级、朴素信仰、骑兵等级、枪兵等级、步兵等级、弓兵等级、车兵/重骑等级、全国人口、野兽等级。

2. 城市属性 民心、军心、腐败、城市耐久、城市人口、城市用间防御。

3. 资源 士子、铁、歌板、马匹、丝绸、城市兵甲、良驹、商队、玄机、词源、酒、香料、熏衣等。

4. 特殊条件（不常见，一般不考虑）

  • A. 取当前国家治所数量
  • B. 取玩家盟国藩属国数量
  • C. 最高城市等级
  • D. 本局损失的兵甲计数
  • E. 名臣姓名字数
  • F. 女性名臣数量
  • G. 好感度超 90 国家数
  • H. 取武将数量
  • I. 人口倍数（100 万为一单位 / 500 万为一单位）
  • J. 存活国家数量
  • K. 取已灭亡国家数量
  • L. 取我国治所地块数量之和
  • M. 玩家累计战斗次数
  • N. 主时代通关数
  • O. 拥有 5 级及以上城市数量
  • P. 取完成的时代政策数量

（十一）是否显示效果

  • 每个效果可以单独决定是否外显。
  • 过于复杂或难以表述的效果可以不对外显示。
  • 默认不勾选。

三、我的备注（待核对）

  1. 攻略类文章说「可重复完成」是填“次数”；本稿是开关 + 必须含计数条件 + 完成后清零。以本稿为准，待客户端确认。
  2. 本稿“达成效果”只列了数值/取值类；但视频里出现「触发剧情」「获得城池」「结盟」「结局」等特殊效果，需补一份特殊效果清单。
  3. 可见条件与完成条件是否共用同一套条件库（四类：逻辑组件/基础/属性状态/属性计数），待确认。
03

触发器

字段全解 · 21 条条件

无悔华夏 · 绘山河 · 触发器（用户整理稿）

来源：用户本人整理，2026-11-16 提供。未经我改写，仅做排版。日期：2026-11-05。

一、触发器综述

触发器没有任何在游戏中可查看的界面，用于设计“满足条件就会发生”的剧本事件或场景事件。许多国家特性就是通过触发器实现的。

二、三个模块

  1. 基础设定：设计触发器绑定的国家，或设为全局触发器，确定效果目标。
  2. 达成条件（触发条件）：激活触发器的条件；计数条件在触发器开启后开始计数。
  3. 达成效果（完成效果）：完成触发后，为效果目标添加的效果。

1. 挂载对象

  • 挂载对象为【国家】时，取条件中挂载国家，可以方便地获取数据。
  • 若选择多个国家，则每个国家挂载的触发器都是单独的副本。若挂载国家灭亡，则对应的这个副本的触发器就不会生效了，不影响其他国家。
  • 挂载对象为【全局】时，不会以任何国家为挂载目标。条件和效果都需要指定具体的某个城市或国家。

2. 初始启用

  • 决定触发器在游戏开始时是否启用。
  • 后续用效果添加的触发器，一定初始处于关闭状态，要用效果指令开启。

3. 循环触发

  • 决定触发器完成后是否会循环开启。
  • 条件中必须存在不取反的计数类型的条件，否则可能被无限触发。
  • 达成触发条件后，计数类型的条件会重新计数。
  • 后续用效果添加的触发器、以及曾被关闭的触发器，初始处于非循环状态，需要用效果指令开启循环。

4. 效果目标

  • 决定触发器完成后为谁赋予效果。
  • 挂载对象是国家时，可选择给挂载国家；全局触发器必须指定一个目标。

5. 编辑器序号

  • 决定编辑器内排序；触发器无游戏内界面，该参数仅在编辑器内有效。

三、达成条件（四类）

（一）逻辑组件

  1. 判断满足条件数（多条件复合）：判断子条件组中是否至少有指定数量的条件已满足。
  • 判断对象：子条件组；参数：最少满足数量（正整数且不超过子条件数）；类型：复合判断。
  1. 判断不满足条件数（多条件复合）：判断子条件组中是否至少有指定数量的条件尚未满足。
  • 参数：最少不满足数量；类型：复合判断。
  1. 返回与否：固定判断为不通过；配置取反后可作为固定通过条件。
  • 判断对象：无；参数：无；类型：状态判断。

（二）基础

  1. 检测目标国家存活：存活则通过。对象：国家；参数：无；状态判断。
  2. 拥有指定的所有城市：直辖拥有全部指定城市时通过。对象：国家；参数：多选城市；状态判断。
  3. 检查目标国家是否为玩家：是当前玩家国家则通过。对象：国家；参数：无；状态判断。
  4. 计时器：随条件启用（使命开局启用／触发器开启时启用），经过一定时间后通过。参数：正整数（秒）；计数判断。
  5. 检测目标国家是否在列表中：属于指定多国之一则通过。对象：国家；参数：多选国家；状态判断。
  6. 玩家是否曾携带武器战斗：存在对应战斗记录则通过。对象：玩家；参数：无；状态判断。

（三）属性状态（国家特性来源）

  1. 检测国家参数在某范围内（大多数国家特性的来源）：判断指定效果值是否处于配置区间，达到最小值且不超过最大值时通过。对象：国家；参数：效果类型（同下方“达成效果”参数池）、最小值、最大值（闭区间）；状态判断。
  2. 已完成国家使命：指定使命完成时通过。对象：国家；参数：选择国家使命；状态判断。
  3. 检测目标城市是否在列表中（原稿写作“检测目标国家是否在列表中”，疑笔误）：判断城市是否属于指定城市列表。对象：城市；参数：多选城市；状态判断。
  4. 检测城市参数在某范围内：判断目标城市指定效果值是否在区间内。对象：治所（非要地）；参数：效果类型、最小值、最大值（闭区间）；状态判断。
  5. 检测两国好感度：判断对指定国家好感度是否在区间内。对象：国家；参数：另一国家 ID、最小值、最大值；状态判断。
  6. 判断国家城市等级之和范围：判断全部非隐藏、非要地城市的等级总和是否在区间内。对象：国家；参数：最小/最大总等级（闭区间）；状态判断。

（四）属性计数

  1. 累计计算触发次数：从启用时累计指定触发类型发生次数，达配置次数后通过。对象：触发来源国家；参数：触发次数（正整数）；计数判断。
  2. 触发时机匹配（疑为“触发时机匹配”）：判断当前事件触发时机是否与配置的触发类型一致，一致的瞬间通过（状态不保存，通常用于触发器）。对象：国家；参数：触发项目；触发时机判断。
  3. 累计计算获取的特殊资源数：从启用时累计获得指定特殊资源，达配置值后通过。对象：国家；参数：特殊资源、获得数量；计数判断。
  4. 累计进攻大捷次数（限制战损）：累计非自动战斗中的攻城大捷；进攻方战损比例不高于上限时计数一次。参数：战损比例上限、完成次数。
  5. 累计进攻大捷次数（限制打出卡牌）：玩家用卡数量不超过上限时计数一次。参数：用卡数量上限、完成次数。
  6. 累计进攻大捷次数（限制时间）：战胜且不超过配置时间计数一次。参数：战斗耗时上限（秒）、完成次数。

四、达成效果参数

注：触发条件里「检测国家参数在某范围内」的参数，同样选这里的效果。

国家属性：国家战斗力、军团规模、威望、科技值、用间等级、全国军队、文化值、修行等级、乐感等级、朴素信仰、骑兵等级、枪兵等级、步兵等级、弓兵等级、车兵/重骑等级、全国人口、野兽等级。

城市属性：民心、军心、腐败、城市耐久、城市人口、城市用间防御。

资源：士子、铁、歌板、马匹、丝绸、城市兵甲、良驹、商队、玄机、词源、酒、香料、熏衣等。

特殊条件：取当前国家治所数量、取玩家盟国藩属国数量、最高城市等级、本局损失的兵甲计数、名臣姓名字数、女性名臣数量、好感度超 90 国家数、取武将数量、人口倍数（100 万/500 万单位）、存活国家数量、取已灭亡国家数量、取我国治所地块数量之和、玩家累计战斗次数、主时代通关数、拥有 5 级及以上城市数量、取完成的时代政策数量。

雪夜入蔡州

触发器填写表 · 示例「雪夜入蔡州」

依据：用户提供的《国家使命》《触发器》百科全量备份 + 编辑器界面。 状态标记：[已确认] = 百科或界面里明确写了；[待确认] = 需要点开下拉核对。 条件库四类：逻辑组件 / 基础 / 属性状态 / 属性计数（界面右上还有“收藏夹”）。

0. 设计目标

玩家扮演唐军，围攻蔡州；若淮西已残（治所少、民心低）则淮西获得“困兽”战力加成；玩家在某一次进攻战斗胜利后触发「雪夜入蔡州」剧情，剧情后开启 AI 反击决策链。

循环触发☑
效果目标挂载国家（淮西）

达成条件：逻辑组件 →「判断满足条件数」，参数 = 3，子条件：

  1. 基础 →「计时器」，参数 = 10（秒）[已确认] —— 这条提供“不取反的计数条件”，是循环的合法前提
  2. 属性状态 →「检测国家参数在某范围内」：效果类型 = 取当前国家治所数量，最小值 0，最大值 2 [已确认]
  3. 属性状态 →「检测城市参数在某范围内」：城市 = 蔡州（治所），效果类型 = 民心，0–39 [待确认：民心属城市属性，用“检测国家参数”能否直接判全国口径]

检查单（每次出表过一遍）

  1. 循环合法性：勾了循环的条件里，必须有不取反的计数条件（计时器/累计次数/特资数）。[已确认]
  2. 多国 ×N：挂载范围选多个国家 = 每个国家一份副本；效果是全局范围时，实际效果 = 副本数 × 单份值。[已确认]
  3. 边沿 vs 电平：触发时机匹配 状态不保存，只在一瞬间为真，不能循环；要“之后一直算数”用累计计算触发次数。[已确认]
  4. 城市条件只看治所：检测城市参数 判断对象是治所（非要地）；判断国家城市等级之和 排除隐藏城与要地。[已确认]
  5. 资源是唯一自由寄存器：读=检测国家参数在某范围内→资源，写=达成效果→资源，数=累计计算获取的特殊资源数。做计数器/伪随机都靠它。[已确认]
  6. 自调用只响一次：触发器不能靠自己循环，要用 1↔2 互相拉起；频率过高会被系统掐断。[视频实证]
