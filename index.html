01这是什么，谁能写

先认清身份，再动手

绘山河是《无悔华夏》内置的自创剧本工坊：你可以把官方剧本当底模，重画疆域、重配势力、重写剧情，甚至用触发器复刻出别的游戏玩法，再发布给别人玩。

两种身份，两道门

  • 游玩者：通关任一主时代剧本即可解锁，进入绘本大厅挑别人的作品玩。
  • 绘师（创作者）：需通关四个主时代剧本且都在一星以上，并同意《创作者协议》。战役、传记类暂不作为创作底图。
小贴士：绘师等级会随作品被游玩的情况成长，解锁更多发布数量与草稿位。经验按玩家平均胜率与时长计算，胜率过高或过低都不给经验——速通本、地狱本都长不了级。

02创作全流程

五个步骤，三张底牌

STEP 1选底图（时代）
STEP 2地图编辑：包装
STEP 3国家编辑：势力
STEP 4城市编辑：地缘
STEP 5剧情编辑：叙事

在这五步之外，编辑器底部还有两个决定剧本「能不能跑起来」的模块：国家使命与触发器。

把它们分成三层看，思路就清楚了：

  • 数据层：地图 + 国家 + 城市——开局长什么样。
  • 叙事层：剧情——玩家看到什么。
  • 逻辑层：国家使命 + 触发器——世界怎么运转。
顺序很重要：先想结局，再倒推使命链，再补触发器，最后写剧情、压数值。反过来做（先写一堆剧情再想逻辑）几乎必然返工，因为剧情页挂不住复杂条件。

03① 选底图

地图是借来的，年代是你自己的

选一个已开放的官方剧本作为「底图」，地图、城池连接关系、基础美术都继承下来，你只改差异。

底图只提供地图骨架，不决定你写什么年代。举个官方自己的例子：想做「五国伐齐」，嫌春秋战国城池太少，就借汉末三国的大地图来画，效果反而更饱满。

首批只开放了部分绘本作底图，官方在持续扩库。绘本标签现在也不再受底图时代限制，可以按你实际写的时代来标。

04② 地图编辑

这是剧本的「对外包装」

子页能配什么
剧本详情名称、年份、可玩势力（多选）、背景音乐
介绍界面进入剧本时那段介绍语
封面与简介用官方素材库的背景 + 人物素材拼封面，写简介
绘本标签架空、小型地图等，决定检索曝光
「可玩势力」是在这里定的：你编辑了八个国家，不等于八个都能被玩，必须在本页勾选。

05③ 国家编辑

势力设定，工作量最大的一页

  • 覆盖国家设置：把某时代整套国家数据（数值、特有兵种、美术）覆盖进来。这是「跨时代混搭」的正规途径——在三皇五帝里塞曹操就靠它。
  • 初始编辑国家 / 选择其他国家：逐个国家划开局版图、增删国家。「开局一个碗」还是「满级大号围殴」随你。
  • 国君信息：头像、旗帜、名字、国号、性格。
  • 国家数值：初始军规、战斗力、钱粮、特资、首都、势力颜色。
  • 战场：初始兵种、特色子弟兵、特色国家卡牌（开局手上那几张）。
  • 势力介绍：常规介绍 + 国家覆灭时的专属描述（灭国文本是单独一栏，最容易漏）。
  • 势力标签：目前纯展示，无数值影响。
跨时代覆盖后，特殊资源不会跟着过来，必须手动重配，否则会出现特资为空或为 0 的怪象。

06④ 城市编辑

地缘与开局资源，决定难度曲线

  • 城市等级 + 所属国家：逐城改归属，等于重画国界。
  • 治所 / 要地互转：本来是要地的城可以改成治所，反之亦然。
  • 隐藏城市：某些城可隐藏，让行军路线不被堵死——做小地图高密度剧本的关键开关。
  • 城市资源：军心、民心、腐化、人口、兵力、产出、城防等级。

这一页直接决定难度：边城城防拉满 + 人口压低 = 拖时间；腹地腐化拉高 = 制造内政压力；给敌国首都塞满兵力 = 逼玩家走外交。

与触发器联动时注意：「检测城市参数」只对治所生效，不含要地；「判断国家城市等级之和」也会排除隐藏城与要地。

07⑤ 剧情编辑

只负责「演」，不负责「判断」

  • 文本库：先存通用文本片段（战报腔、史官旁白），写情节时反复调用，避免同一段话手打五遍。
  • 撰写新情节：局内对话形式，逐幕配对话头像 + 台词，这是最接近视觉小说的部分。
  • 关键节点：每个势力分别配 开场 / 胜利 / 失败 三段。
  • 详细剧情：三种触发方式——消灭某国、占领特定城池、随大地图时间推移。
剧情页自己不会判断复杂条件。想做「实力超过对方两倍才弹这段」，必须靠国家使命或触发器去触发剧情，而不是在剧情页里写条件。

08⑥ 国家使命

玩家看得见的任务系统

就是官方剧本里一路推着你走的「国家使命」任务栏。创作者版由四部分构成：基础设定、可见条件、完成条件、达成效果。

四部分各管什么

部分作用
基础设定绑定国家、基础参数与特性
可见条件满足后才出现在玩家任务列表
完成条件玩家要达成的目标
达成效果完成后的奖励与特殊效果

字段逐条说清

  • 使命标题：7 个字以内（很紧，「雪夜入蔡州」刚好卡线）。
  • 编辑器序号：只在编辑器内排序，不影响游戏内顺序。
  • 排序：决定游戏内使命列表的先后，从小到大。
  • 可见国家：可多选；条件里选「挂载国家对象」时，按每个国家分别计算。
  • 使命类型：普通使命不触发结局；终局使命触发结局（如民心低于 10 触发叛乱失败）。
  • 可重复完成：条件里必须含计数类条件（如计时器），否则可能被无限完成；完成后计数条件清零重计。
  • 不可见隐藏：开启后，可见条件不满足时使命会再次隐藏（例：可见条件设为「秦存在」，秦亡则任务不可用）。
  • 奖励说明：≤20 字；奖励项目：≤6 字 + 图标。
  • 是否显示效果：每个效果可单独决定外显，默认不勾选。

达成效果能改什么

国家属性：战斗力、军团规模、威望、科技值、用间等级、全国军队、文化值、修行等级、乐感等级、朴素信仰、各级兵种等级、全国人口、野兽等级。

城市属性：民心、军心、腐败、城市耐久、城市人口、城市用间防御。

资源：士子、铁、歌板、马匹、丝绸、城市兵甲、良驹、商队、玄机、词源、酒、香料、熏衣……

特殊取值：治所数量、盟国藩属国数、最高城市等级、本局损失兵甲、名臣姓名字数、女性名臣数量、好感超 90 国家数、武将数量、人口倍数、存活/已灭亡国家数、治所地块数和、玩家累计战斗次数、主时代通关数、5 级以上城市数、完成的时代政策数。

关键联动：「检测国家参数在某范围内」的参数池，就是上面这一整张表。条件能读什么、效果能改什么，是同一套指标。

09⑦ 触发器

隐藏的引擎，国家特性的真正来源

触发器在游戏里没有任何界面，只负责「条件满足 → 执行效果」。官方说法：许多国家特性就是靠触发器实现的。

三个模块：基础设定 / 达成条件 / 达成效果

  • 挂载对象 · 国家：绑定到指定国家，能方便地取该国数据；选多个国家 = 每个国家一份独立副本。挂载国灭亡，该副本失效，不影响其他国家。
  • 挂载对象 · 全局：不挂任何国家，不随灭国消失；但条件与效果都必须指定具体的国家或城市，且效果目标只能选一个。
  • 初始启用：勾了开局就启用；被效果添加的触发器，一定初始关闭，要用指令开启。
  • 循环触发：条件里必须有不取反的计数类条件，否则可能被无限触发；达成后计数条件重新计数。新添加的、曾被关闭的触发器，初始都是非循环，要循环得再发一条指令。
  • 效果目标：给谁加效果。国家挂载可选挂载国；全局触发器必须指定目标。
  • 编辑器序号：仅编辑器内排序。

达成条件：四类共 21 条

类别条目
逻辑组件判断满足条件数（多条件复合）、判断不满足条件数（多条件复合）、返回与否
基础检测目标国家存活、拥有指定的所有城市、检查目标国家是否为玩家、计时器、检测目标国家是否在列表中、玩家是否曾携带武器战斗
属性状态检测国家参数在某范围内、已完成国家使命、检测目标城市是否在列表中、检测城市参数在某范围内、检测两国好感度、判断国家城市等级之和范围
属性计数累计计算触发次数、触发时机匹配、累计计算获取的特殊资源数、累计进攻大捷次数（限制战损 / 限制打出卡牌 / 限制时间）

三个最常用的「机关」

① 与 / 或 / 非：判断满足条件数 的参数设 1 = 或，设满 = 与；配合 返回与否 + 取反 = 恒真，用来「站位置」让触发器必定触发，或者反过来把某个触发器「废掉」（永远不满足）。

② 边沿 vs 电平：触发时机匹配 只在那一刻为真（状态不保存），不能循环，适合「下一次攻城胜利时」；累计计算触发次数 达成后一直为真，可循环。选错会导致玩家事后补条件也能吃到奖励——经典 bug。

③ 触发器六兄弟：添加、开启、关闭、移除、设为循环、取消循环。用它们搭状态机与 IF/ELSE。注意：自己调用自己只能响一次，要靠 1↔2 互相拉起；频率过高会被系统掐断。

三条隐性坑：多国挂载 × 全局效果 = 效果 ×N；特资是唯一自由寄存器，容易被剧本事件污染，做计数器要选没人碰的特资；循环被掐断会静默停摆，定时器可能某回合就不动了。

10两者如何配合

四种范式，够写九成剧本

  • 事件链：使命的可见条件里判断「上一条使命已完成」，形成 A→B→C 的任务链。
  • IF / ELSE：成对触发器同时拉起，各自的效果里移除对方、再拉起下一组。互删就是互斥锁，绕开「同一帧谁先执行」的不确定性。
  • 状态机：用六兄弟开关触发器，模拟变量的「置位 / 复位」。
  • 伪随机：计时器给某个特资累加 → 两个互相调用的触发器反复减去周期做「取模」 → 需要随机的分支读特资数值分派。改进三招：改步长、加长周期辅助计数器、扩大取值空间或加第二个特资。
判断谁该干什么：使命把选择权交给玩家，适合主线与结局；触发器在暗中改世界，适合国家特性与动态难度。触发器不要轻易插剧情、更不要做结局——完成条件不稀有的话，体验会很糟。

12检查单与延伸

发出去之前，过一遍

  1. 循环合法：勾了循环的条件里，必须有不取反的计数条件。
  2. 副本倍数：挂多国 + 全局效果 = ×N，确认你要的就是 N 倍。
  3. 边沿/电平：一次性事件用 触发时机匹配，长期累计用 累计计算触发次数。
  4. 城市条件只看治所；等级之和排除隐藏城与要地。
  5. 新建触发器默认关闭且非循环，记得用指令开启 / 设为循环。
  6. 字数：使命标题 ≤7 字，奖励说明 ≤20 字，奖励项目 ≤6 字。
  7. 外显：效果默认不显示，想给玩家看得手动勾。
